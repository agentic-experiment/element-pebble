# Element Pebble

A browser-based arcade survival game. You are a small pebble that can shift between four elements. Move through the arena, absorb matching elemental motes, avoid mismatched ones, build combos, and unleash a clearing pulse when your charge is full.

## Step-by-step reasoning

1. Chose a static, dependency-free HTML/CSS/JavaScript structure so the game runs directly on GitHub Pages.
2. Designed a canvas-based 2D game with a circular arena, animated background, particles, trails, and glow effects.
3. Implemented four elements (Ember, Tide, Stone, Zephyr), each with distinct colors and a matching hazard type.
4. Added player movement with keyboard and pointer/touch dragging, plus boundary handling inside the arena.
5. Added hazard spawning with increasing speed and frequency over time.
6. Implemented collision rules: matching elements are absorbed for score, combo, and charge; mismatched elements cost a life.
7. Added a charge meter and pulse ability that clears all hazards of the current element.
8. Added lives, game-over state, high score persistence, pause, mute, and restart controls.
9. Added responsive HUD, title, pause, and game-over overlays plus touch element buttons.
10. Verified the JavaScript syntax with `node --check`.
